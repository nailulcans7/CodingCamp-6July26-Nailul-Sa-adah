# BudgetVis - Expense & Budget Visualizer

## Deskripsi
Aplikasi web untuk tracking pengeluaran harian dengan visualisasi chart.

## Fitur
- Form input transaksi
- Pie chart visualisasi
- Sorting transaksi
- Dark/light mode
- Monthly summary
- Custom categories
- High expense warning

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
- LocalStorage

## Cara Menggunakan
1. Clone repo ini
2. Buka index.html di browser
3. Mulai tracking pengeluaran!
